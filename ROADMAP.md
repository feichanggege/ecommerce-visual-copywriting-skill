# Roadmap

`SKILL.md` is the canonical v3 entrypoint. This roadmap tracks maintained capabilities and remaining work; it does not promise release dates.

## Current baseline

- Four modes: Standard, One-shot, Audit/revision, Designer handoff.
- Evidence ledger → conversion driver → Campaign Style Lock → Storyboard → execution cards → hard blockers and the five-dimension 80-point self-review with its record.
- Dynamic image counts, reference fidelity, negative constraints, and cross-border localization.
- Six conversion drivers, including price/bundle/promotion.
- Copy limits, mobile readability, and post-production typography by default.
- Separate platform playbooks, output contracts, and official source notes.
- Chinese and full English skill companions with section-alignment checks.
- Lightweight showcase assets, a worked example, and installation guidance for Codex, Claude Code, and Claude.ai.

## Contribution standard

Use [CONTRIBUTING.md](CONTRIBUTING.md). Rule changes need applicable official sources, an affected example, matching Chinese/English updates, and validation evidence. No invented product facts, approval guarantees, arbitrary scoring thresholds, or automatic publication.
