# 电商平台视觉 Playbooks

> 本文件描述长期相对稳定的“页面任务分工”和视觉策略，不替代平台当前官方政策。尺寸、比例、主图限制、类目资质、禁限词、促销规则等易变化内容，必须在需要时核验官方最新来源。

## 使用方法

1. 先确认平台、市场和商品类目。
2. 只读取对应平台段落。
3. 把平台目标与商品的主成交驱动力合并，不要机械套模板。
4. 如果用户问的是“现在能不能这样做”，转为官方规则核验任务。

## Amazon

### 视觉目标

优先解决：搜索结果识别、产品理解、差异比较、可信度和购买决策。

### 推荐任务分工

- **Hero**：产品身份最清晰，减少干扰，优先让用户快速识别包装、形态、数量或组合。
- **Benefit**：把最关键参数翻译成用户收益。
- **Proof**：产地、工艺、材质、测试、认证等真实证据。
- **How it works / How to use**：操作步骤、冲泡方式、安装方式、兼容关系。
- **Comparison / Selection**：规格、型号、口味、组合选择，降低选择成本。
- **Lifestyle**：真实使用场景和比例感。
- **A+ / Brand Story**：承担更完整的品牌、工艺、系列和信任叙事。

### 注意

Amazon 对主图、A+、类目和宣称的具体要求可能因站点和类目变化。涉及“主图能否加字”“背景要求”“图片数量/尺寸”等问题时，查对应站点官方 Seller Central 文档，不凭经验直接断言。

## Shopify / DTC 独立站

### 视觉目标

平台模板限制相对少，重点是品牌一致性、首屏说服、页面节奏、信任机制和结账前异议处理。

### 推荐 PDP 结构

- Above the fold：产品 + 单一价值主张 + 价格/规格/CTA + 关键社会证明或信任元素。
- Top Benefits：3 个以内的主要购买理由。
- Product Story / Mechanism：解释为什么值得买。
- Proof：材料、工艺、检测、来源、品牌证据。
- Lifestyle：目标人群与场景。
- Comparison / Variants：系列或规格选择。
- FAQ：配送、使用、规格、售后、顾虑。
- Final CTA：重复核心价值，不新增未经证明的卖点。

### 注意

Shopify 本身不是广告和消费者保护规则的豁免区。页面仍受目标市场法律、支付/广告渠道政策和商品类别规则约束。

## TikTok Shop / 抖音小店

### 视觉目标

移动端、快速理解、视频/直播协同、第一屏截流和原生内容感。

### 推荐策略

- 文字更短，避免把详情页长文案搬到主图。
- 第一视觉落点优先展示产品 + 立即能理解的购买理由。
- 强化真实使用场景、动作、结果过程，但不要制造无法证明的“前后效果”。
- 图、短视频、直播口播的卖点口径保持一致。
- 价格、促销、功效、类目资质等内容需要按当前平台规则核验。

## 淘宝 / 天猫

### 视觉目标

搜索/推荐场景中的视觉截流 + 详情页的利益密度和信任叙事。

### 推荐策略

- 主图组分工明确：Hero、核心利益、差异、场景、规格/活动信息。
- 详情页按“承接 -> 利益 -> 证据 -> 场景 -> 选择 -> FAQ”推进。
- 品牌旗舰店可增加品牌资产、系列矩阵和视觉一致性。
- 当前敏感词、促销、类目规则需核验平台最新规范。

## 京东

### 视觉目标

产品理解、参数可信、规格选择和理性决策。

### 推荐策略

- 参数不要只抄说明书，要翻译成使用收益。
- 参数页、包装、详情页的规格和型号必须一致。
- 对家电、3C、设备类商品，重点做兼容、尺寸、功能机制和使用条件可视化。
- 资质/参数类信息优先保证一致和可追溯。

## 拼多多

### 视觉目标

快速识别、价格/组合理解、核心利益高密度表达。

### 推荐策略

- 在不牺牲真实性的前提下提高第一屏信息效率。
- 优先清楚表达“买到什么、多少、什么规格、解决什么问题”。
- 避免为了强转化使用无法证明的极端价格、最低价、唯一性或夸张效果表述。

## Temu

### 视觉目标

移动端快速理解、商品差异、组合/规格和性价比感知。

### 推荐策略

- Hero 清楚展示商品本体、数量和组合关系。
- 用图示降低跨语言理解成本。
- 文案短、数字清楚、规格明确。
- 目标市场语言与单位本地化，不要只做中文直译。
- 当前类目、图片和促销政策需实时核验。

## Shopee / Lazada

### 视觉目标

移动端浏览、规格理解、场景代入、本地语言表达和信任。

### 推荐策略

- 首图强调商品身份和核心差异。
- 规格、数量、尺寸、适配关系尽量图示化。
- 场景、人群、节日和生活方式按当地市场重写。
- 注意多语言排版长度，不让翻译后文本破坏层级。
- 物流、促销、类目资质、主图限制等以各站点当前官方规则为准。

## 跨境本地化通用规则

不要逐字翻译。至少检查：

- 目标市场消费者是否理解该卖点。
- 单位是否本地化，如 g/oz、cm/in 等。
- 食用、使用、送礼、家居等场景是否符合当地习惯。
- 中文里依赖文化语境的表达是否需要解释或重写。
- 品牌名、产品名、产地名、茶类/食品类名词是否统一。
- 合规边界是否按目标市场重新判断。
- 页面文字密度是否适合英文或其他语言的长度。
