## 3. 宣称—证据台账

每条可验证宣称使用唯一 Evidence ID。无证据的数字、资质、对比、销量、评价或效果不得进入可上线文案。

| Evidence ID | 候选宣称 | 证据来源/编号 | 状态 | 可上线表达 | 必要声明 |
|---|---|---|---|---|---|
| E-01 |  |  | 可用 / 待核 / 禁用 |  |  |

状态规则：

- 可用：用户已提供可核验依据，且表达未超出依据范围。
- 待核：保留在内部备注，不进入可上线文案。
- 禁用：删除或改为不依赖该证据的中性表达。
